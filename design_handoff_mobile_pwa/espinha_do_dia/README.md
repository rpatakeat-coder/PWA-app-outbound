# Handoff · App de rua otimizado (a espinha do dia)

Takeat Field Sales · 28/10/2026

**Comece por `PROMPT-CLAUDE-CODE-APP-DE-RUA.md`.** Ele tem as 10 perguntas que o Claude Code responde antes de codar, o que não se mexe, o que construir (em 3 fases), os textos exatos, as regras, os dados, os eventos e o checklist de aceite.

```
PROMPT-CLAUDE-CODE-APP-DE-RUA.md    o pedido para o Claude Code
prancha/
  App de rua otimizado - Prancha.dc.html   referência principal: 6 abas → 3, ciclo da porta, Hoje, Eu, cobrança
  Espinha do dia - Prancha.dc.html         detalhe de abrir e fechar e os estados da linha do dia
  support.js · mapa-base.svg · takeat-t-branco.png   necessários para abrir as pranchas
ref/
  PEDIDO-dia-do-executivo.md         pedido original, números medidos e decisões de Julyan
  PROMPT-anterior-AGENDA.md          pacote do qual este depende (não refazer)
  PROMPT-anterior-TAREFAS-POR-DIA.md pacote do qual este depende (não refazer)
  PLAYBOOK-gatilhos.md               tabela de gatilhos da Fala pronta e do "Se ele disser"
```

Abra as pranchas direto no navegador, com a pasta `prancha/` inteira. Cada celular tem um id (1a, 2c…) para referência.

Em uma frase: **o executivo não sai do mapa, então tudo vai até o mapa.** Plano ao abrir, fala na porta, próximo passo ao sair, ligação entre portas, placar na linha do dia, fecho às 18h. O gestor vê quem não planejou e monta o dia dele no Cockpit. Nada trava.
